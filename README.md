# keeevinw.github.io

Personal website of Xuanye Wang — live at **https://keeevinw.github.io/**

Plain HTML, CSS, and a little JavaScript. No build step: GitHub Pages serves the files as-is.

| File | What it is |
| --- | --- |
| `index.html` | Home page |
| `teaching/index.html` | Teaching portfolio for EDS 124BR (served at `/teaching/`) |
| `styles.css` | Shared layout, typography, and light/dark themes |
| `script.js` | Theme toggle, nav highlighting, copy-email button |

## Preview locally

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```
